# 0005. Both apps are Cloudflare Workers deployed by Workers Builds

Status: accepted, 2026-10-26

## Context

ayagmar.dev already uses Cloudflare nameservers. The site is static apart from one check; signals needs cron, D1 and secrets. Deploy credentials should not live in GitHub.

## Decision

- `site` is a Worker with static assets (`apps/site/wrangler.jsonc`). Its script runs first only for `/` (`assets.run_worker_first: ["/"]`). A user agent starting with `curl/`, `Wget/`, `HTTPie/` or `xh/` gets the prebuilt `index.txt`; everything else gets `index.html`. Both are fetched through the `ASSETS` binding, which applies the `_headers` rules, and the Worker adds `Vary: User-Agent`. Every other path is served by the asset layer without invoking the Worker. Unknown paths get `404.html` with status 404.
- `signals` is a Hono Worker on the `api.ayagmar.dev` custom domain with a D1 binding `DB`.
- Workers Builds builds and deploys `main` and uploads a Preview for every other branch. Steps are in `docs/deploy.md`.
- Previews use the `previews` block of each `wrangler.jsonc`, following the current Previews docs: their own `vars` and a shared `min7-signals-preview` D1 database, never production bindings. Its migrations are applied with `apps/signals/wrangler.preview-migrations.jsonc`.
- Both Workers enable Workers Logs and Traces (`observability.enabled`, `observability.traces.enabled`), log structured JSON, and use the compatibility date of the day they were created (2026-10-26). Advancing it is a reviewed change.
- `Env` types are generated by `wrangler types` (`just typegen`, run by `just typecheck`) into `worker-configuration.d.ts`, which is gitignored and never edited by hand.

## Consequences

Everything fits the Workers Free plan. The site Worker is invoked only for `/`, so assets elsewhere cost no Worker requests. `workers_dev` is off; Previews use `preview_urls`.
