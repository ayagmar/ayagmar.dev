`headroom` is a Noctalia bar widget. It shows how much of each plan window you have used, turns amber or red as you near the limit, and opens a panel with every window, when it resets and where your current rate will take you by then.

It reads the sign-ins the Claude Code, Codex and Antigravity CLIs already saved, so there are no API keys to set up, and it shows each Claude or Codex account when you have more than one.

This repository is archived. Headroom now lives in [noctalia-dev/community-plugins](https://github.com/noctalia-dev/community-plugins/tree/main/headroom), which is where Noctalia installs it from.
