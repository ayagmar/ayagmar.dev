`agents-skills` holds my skills for pi, Claude Code, Codex and Cursor, in the [Agent Skills](https://agentskills.io/specification) format. Each one is its own npm package, so you install the one you want with the skills CLI, pi or a plugin marketplace.

Most are instructions only: writing commits, reviewing a codebase, planning and checking plans, writing without filler. A few run scripts, such as searching local agent session history or working out what sessions cost; those read the session stores and never write to them.

They are listed, with what each does, on [/skills](/skills).
